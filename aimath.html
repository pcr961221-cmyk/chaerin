문제 1 · 문자열의 해밍 거리

기준 문자열과 가장 유사한 문자열 찾기

기준 문자열 T와 세 문자열 A, B, C가 다음과 같습니다. 모든 문자열의 길이는 10입니다.

구분문자열
기준 T1011001010
A1010001011
B0011001010
C1110010011
  1. T와 A, T와 B, T와 C의 해밍 거리를 각각 구하세요.
  2. 해밍 거리를 비교하여 T와 가장 유사한 문자열 하나를 찾으세요.

해밍 거리: 같은 위치에 있는 문자가 서로 다른 위치의 개수입니다. 해밍 거리가 작을수록 유사하다고 판단합니다. 위치는 왼쪽부터 1번째, 2번째, …, 10번째로 셉니다.

문제 2 · 이미지의 해밍 거리

새로운 이미지 D와 가장 유사한 이미지 찾기

기준 이미지 A(십자 모양), B(X자 모양), C(사각 테두리)와 일부 칸이 달라진 새로운 이미지 D를 비교합니다. 각 이미지는 6×6 행렬이며, 검은색은 0, 흰색은 1입니다. 칸 안 숫자가 해당 위치의 행렬 성분입니다.

위 이미지는 모두 고정되어 있습니다. 학생이 색이나 숫자를 바꿀 수 없습니다.

  1. H(D, A), H(D, B), H(D, C)를 각각 구하세요. 같은 행·같은 열의 값을 비교하세요.
  2. 계산한 거리를 비교하여 새로운 이미지 D와 가장 유사한 기준 이미지를 고르고, D를 어떤 도형으로 분류할지 쓰세요.

풀이에는 각 비교에서 행별로 다른 칸의 수를 적고, 여섯 행의 값을 모두 더해 해밍 거리를 구하세요. 예: 1행 …개 + 2행 …개 + … + 6행 …개.

문제 3 · 합성곱

필터를 적용하여 출력 행렬 구하기

입력 행렬 A에 필터 B를 적용합니다. 필터를 오른쪽 또는 아래로 1칸씩 이동하면서 합성곱의 출력 행렬을 구하세요.

입력 A · 4×4

필터 B · 3×3

계산 규칙: 필터를 뒤집지 않고 겹칩니다. 같은 위치의 성분끼리 곱한 9개의 값을 모두 더해 출력의 한 성분을 구합니다. 입력 테두리에 값을 추가하지 않습니다(패딩 없음).

  1. 왼쪽 위에서 시작해 필터를 이동시키며 출력 2×2 행렬의 네 성분을 구하세요.
  2. 각 성분을 구하는 곱셈·덧셈 과정을 쓰고, 최종 출력 행렬을 쓰세요.

출력의 (1,1)은 입력의 1~3행·1~3열, (1,2)는 1~3행·2~4열, (2,1)은 2~4행·1~3열, (2,2)는 2~4행·2~4열 영역을 이용합니다.
